# 视觉专刊性能优化 · 2026-10-23

针对滚动卡顿与跟随迟滞，保留现有图像、构图、金属材质、持续运动、视差和溶解转场。以下区分可由代码和测试确定的工作量变化，以及仍需浏览器复测的体验结果。

## 已实现

- 共享姿态通过 WeakMap 中的稳定对象传递。取消在整个 hero 上逐帧写入可继承的滚动/指针变量；只在值变化时写入五个实际消费数值的叶节点，三个私有变量均声明为不继承。纯指针运动不更新 DOM 样式、不读尺寸。
- 指针事件只记录坐标；滚动/resize 才使几何缓存失效。滚动与指针的时间常数分别为 90/110ms，三维物件直接使用已经平滑的姿态，去除第二层位置缓动。暂停保留同一姿态，恢复时不累计后台时间。
- 两层云保留原 UV/顶点，删除遮罩确定为零的三角形：每层 4,608 → 2,000 个。初屏提交三角形合计 27,520 → 22,304，减少约 19%；原六次绘制及可见构图保持一致。
- 金属扭带每顶点以一次曲面求值同时给出位置和解析切向量，替代此前位置及法线差分的五次求值。金属、反射、细分与动态曲面保持原配置；数值差分和半扭接缝回归通过。这是求值次数变化，不代表整个 shader 耗时减少 80%。
- 人物使用包含布料最大位移的包围盒剔除。景层仅在 alpha 上界低于 shader 丢弃阈值时隐藏，逆滚可恢复。完全溶解后清空一次画布，随后不提交空场绘制。
- 装饰画布基础 DPR 上限从 1.25 调为 1，并限制到 200 万基础像素；在原 DPR 达上限且未触发预算时，像素数量减少 36%。HTML 字体和布局不受影响。平均帧间隔连续两秒超过 24ms，画布质量才逐级变为 85%/70%；稳定低于 17ms 十二秒后才逐级恢复，避免频繁 resize。离屏、暂停、后台时停止绘制。

## 基线与复测限制

优化前，在生产构建、1440×900 视口、RTX 5060 Laptop / 160Hz、4 倍 CPU 节流下，记录 720 个原生 RAF 间隔，并以 80ms 间隔下滚/上滚各 20 次（每次 wheel delta 25，测试环境对应约 100 CSS px）。测量在绘画纹理和首帧就绪后开始，其他预览暂停。

| 优化前指标 | 结果 |
| --- | ---: |
| RAF 平均间隔 | 11.92ms |
| RAF p95 | 25ms |
| 大于 25ms 的间隔 | 18 / 720 |
| 样式重算耗时 | 3.657s / 8.614s 采样窗口 |
| 脚本执行耗时 | 1.368s |
| Layout 次数 / 耗时 | 3 / 0.00248s |

这项压力基线指向样式重算，不能代表所有用户设备的实际帧率。未节流的早期基线平均间隔约 6.36ms，说明“迟滞”也可能来自叠加缓动，不能仅以平均 FPS 判断。

会话恢复后，浏览器工具拒绝获取本地预览的访问权限；未绕过限制，也没有完成优化后同条件 RAF/GPU 复测。因此本记录不报告 FPS 提升百分比，不将三角形/像素减少量视为实测帧率收益。仍需在可用浏览器内核下复测快速滚动、反向滚动、鼠标视差和移动设备的视觉清晰度。

## 回归验证

- 前端全套：78 个文件、403 项测试通过。
- 场景定向回归涵盖 30/120fps 一致性、指针零几何读取/零样式变更、相同值零 DOM 写入、暂停/后台/卸载、空场清理与逆滚恢复、慢帧降分辨率和长窗口恢复。
- 几何回归涵盖云层遮罩边界、解析偏导与数值差分、半扭接缝、布料位移包围盒、透明剔除阈值和资源释放。
- 完整 Vite + SSG 构建生成 88/88 个主题、5/5 个系列、141/141 篇文章。构建保留既有编辑器分包大小与 Browserslist 数据提示；本次不修改生产写接口或内容发布配置。
