# AI 信号观测站 · 视觉与动态设计

2026-10-23。当前科技版首页参考 Shopify Winter ’26 的全屏空间、镜头推进、前后景错位和章节衔接，使用原创文案、程序建模与组件；未复用 Shopify 的场景资产、标识或源码。

## 主体与页面节奏

主体是一台银蓝色信号接收装置：凹面天线、穿孔面板、背肋、馈源、支撑杆与机械底座共同构成可辨认的物体。“收集信号，读到来源与背景”连接 AI 新闻站的用途。旧版花园、石雕手和抽象玻璃多面体不再出现在运行页面。

1. **收集信号**：首屏左侧提供标题、四章入口、真实文章数量与本页最新发布日期；右侧实时渲染接收装置。桌面首屏还展示最近发布文章的真实标题与链接。
2. **进入信息流**：封面文字退场，接收装置移入远景，镜头向前飞行，深浅不同的星尘和信号轨迹形成运动方向。
3. **接入报道**：信号阵列向平面收拢，站内首条新闻的封面和标题进入场景；银白阅读面接棒，进入可操作的本期头条。
4. **新闻档案**：保留搜索、标签、分页和双列图片新闻流，手机改为单列。三条焦点报道手动切换，标题、图片、日期、来源与预览保持同步。
5. **领域与订阅**：程序 SVG 信号网络连接模型、开源、算力三个方向，入口指向站内关键词搜索；日报、周报、系列、归档与订阅回归浅色阅读面。

## 视觉与运动实现

- 深蓝场景 `#050c1d`，银白阅读面 `#f1f5fa`，深蓝文字 `#101d35`，电蓝 `#3269f5` 与青色 `#67d8f4`。标题采用粗无衬线，辅助仪表文字用等宽字。普通栏目、正文及无 JS 预渲染使用同一阅读体系。
- 首屏采用原生 sticky 舞台，桌面约 220svh；触屏适度缩短。滚动不被劫持，四章保持可分享和刷新恢复的原生锚点。
- 滚动与指针使用基于时间的指数阻尼，停滚后继续收敛，反向滚动平滑改变方向；只更新 CSS 变量，不逐帧重渲染 React。三维镜头真实改变位置，主体变换、粒子深度和新闻图层分别编排。
- Three.js 按需导入，DPR 上限 1.5。场景用程序几何、材质和纹理生成，无额外模型、场景图片或远程素材下载。新闻封面仍使用文章原有的图片代理和失败回退。
- 动态可手动暂停；离屏、后台与暂停时停止 RAF。减少动态效果偏好下取消长滚动场景，显示静态首屏。不支持 WebGL2 或上下文丢失时显示程序 SVG 装置。
- 阅读内容默认可见；标题、图片与主题线稿仅在观察器就绪后启用渐进增强，离屏停止循环。章节目录避让首屏，桌面在左下、小屏在底部。
- 数量或日期不可用时明确显示未知状态，不将请求失败呈现为零篇，也不标记为实时快讯。主视觉标注为原创交互场景、非新闻实拍。
- 报刊版、登录与后台保持独立主题。场景不加载到文章、搜索或私有路由。

## 维护入口

- `EditionHero.jsx`：首屏文字、真实头条交接、暂停控制。
- `buildSignalObservatory.js`：接收装置、信号轨迹、星尘、相机与资源释放。
- `IntelligenceSculpture.jsx`：渲染器及可见性、暂停、减少动态效果和降级生命周期。
- `useEditionScene.js`：滚动与指针阻尼；`news-signal-hero.css`：全屏构图与新闻转场。
- `EditionChapterNav.jsx`：章节定位与目录；`TechTopicExplorer.jsx`：程序 SVG 主题图形。
- `news-tech-*.css`、`news-edition.css`、`scripts/prerender-public.mjs`：阅读与静态页面样式。

旧图像及生成提示词保留为历史设计资产，当前首页不引用它们。数据仍来自既有公开 API；此次改造不代表生产内容流水线已恢复持续更新，恢复条件见项目审查文档。
