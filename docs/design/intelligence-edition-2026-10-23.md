# Intelligence Edition · 沉浸式视觉专刊

2026-10-23。以 Shopify Winter ’26 的满屏绘画构图、极简浮层目录、独立景深和连续滚动转场为参考。视觉使用原创生成的人物与环境、程序渲染的前景物体；不复用参考页资产、标识或源码。

## 构图

- 取消设备产品页的左文右物布局。古典浮空花园铺满视野，两位大幅人物在左右前景相望，背景保留云层、湖面、建筑和植物的远近关系。
- 中心是窄幅透明细框封面：智能新纪元、英文刊名、四章文字目录和真实内容日期。顶部为透明单行导航，完整栏目及版式选择保留在菜单中。
- 酸性青柠与银色金属扭带作为可旋转的现代前景物体，与古典画面形成鲜明冲突。独立场景层与真实三维反射共同构成画面，不能退化为整张背景图平移。
- 进入阅读区后直接接本期真实头条，取消重复的“A closer look”口号和重复头条封面。首页阅读面改为暖中性色，其他普通栏目保持现有阅读主题。

## 动态分镜

1. 首屏人物、环境、前景各自缓慢运动，指针带来不同幅度的空间视差，HTML 文字稳定可读。
2. 滚动初段，中心封面退场，角落刊名与章节目录接棒。
3. 中段人物分离、远近景错开，金属扭带翻转推进，镜头在场景中连续移动。大字章节与完整美术场景同屏，避免空背景和孤立口号。
4. 末段景层通过颗粒溶解过渡，暖色阅读面接入实际新闻。正常搜索、筛选、分页、焦点切换与预览不依赖场景动画。

滚动采用单层、基于时间的阻尼，停滚后继续收敛、反向平滑改变方向。三维渲染器直接读取共享姿态，仅五个文字/过渡叶节点更新非继承 CSS 变量，不逐帧重渲染 React。原生 sticky 与锚点不劫持滚动，支持四章分享、刷新恢复与键盘操作。

## 降级与性能

- 图像纹理与首帧就绪后才显示 WebGL，加载与失败期间使用同一组正式图层构成静态画面。
- Three.js 按需导入；装饰画布 DPR 上限 1、基础像素预算 200 万，连续慢帧才逐级调整分辨率，HTML 文字维持原生清晰度。离屏、后台和暂停时停止 RAF，取消时释放纹理、材质、几何和渲染器。
- 完全透明和离开视野的景层不提交绘制，反向滚动时恢复；云层裁掉遮罩恒为透明的三角形，金属曲面使用解析法线，保留原材质与连续形变。详细证据与测量限制见[性能记录](edition-performance-2026-10-23.md)。
- 提供手动暂停。减少动态效果偏好下取消长滚动场景，显示静态封面；WebGL2 不可用或上下文丢失时仍能阅读与导航。
- 艺术场景明确标记为原创交互画面、非新闻实拍。新闻仍显示原文章图片和真实日期，数量失败不显示为零。
