# Intelligence Edition · 视觉专刊

2026-10-23。当前科技版首页采用沉浸式视觉专刊，参考 Shopify Winter ’26 的整屏场景、章节叙事和阅读面切换。使用原创插画、文案和组件；未复用 Shopify 资产或标识。

## 页面节奏

1. **封面**：古典花园、石雕手与荧光玻璃多面体构成空间；前景的透明玻璃环独立运动。中间是真实 HTML 封面、四章目录、文章总量与本页最新发布日期。
2. **本期焦点**：场景通过纸边进入象牙色阅读面。大号中英衬线标题承接真实头条，前三条报道可手动选择，标题、日期、来源、图片与预览同步切换。
3. **新闻档案**：保留完整搜索、标签、分页和双列图片新闻流；手机单列。数据失败显示不可用，不冒充零条或实时数据。
4. **领域探索**：深橄榄绿色场景和原创建模线稿形成第二个视觉段落，入口明确指向模型、开源、算力关键词搜索。
5. **阅读与订阅**：日报、周报、系列、归档与订阅方式回归安静的纸面。

## 视觉与交互

- 纸面 `#eee9df`，墨色 `#1b241d`，强调色 `#c6f268`；常规栏目、正文与静态预渲染保持同一体系。
- 浮动目录在离开封面后出现：桌面位于左下，小屏改为底部四章导航，给页末与返回顶部按钮预留空间。
- 原生锚点可键盘操作，直接打开章节链接会在新闻数据就绪后恢复位置，无滚动劫持；观察当前章节显示位置。
- 场景滚动只更新 CSS 变量，一帧至多一次，离屏停止；`prefers-reduced-motion` 下停止视差和漂浮。
- 仅封面背景优先加载；透明前景延迟、低优先加载。主场景 JPEG 约 455 KB，透明物件 PNG 约 2.49 MB。
- 插画均标为非新闻照片，新闻封面继续使用原文章素材。缺图与坏图使用明确的占位，不生成虚构新闻证据。
- 顶部保留报刊版切换；登录与运营后台使用独立语义主题。
